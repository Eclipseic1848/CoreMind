# Triage labels

工程 Skills 使用五种标准分流角色。本仓库直接使用同名 GitHub 标签。

| Skill 中的角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交给 Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策 |
| `wontfix` | `wontfix` | 确认不处理 |

当 Skill 使用角色描述时，应应用本表对应的 GitHub 标签，不创建同义或重复标签。
