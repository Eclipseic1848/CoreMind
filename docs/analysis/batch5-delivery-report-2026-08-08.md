## GitHub 用户入口

根目录保留 GitHub 自动识别的 `README.md`、`CONTRIBUTING.md`、`LICENSE` 和 `SECURITY.md`。README 明确三种入口、快速开始、能力边界、当前 Alpha 状态和学习路径；贡献指南从环境准备延伸到测试、双语材料、供应商证据和 Pull Request；安全策略修正了 Linux、Windows 与自定义工具的真实隔离边界。

此外增加中英文行为准则、结构化 Bug/功能模板和 Pull Request 检查表。标准 MIT 许可证保持原文，避免对许可证文本做装饰性修改。

## 文档站

文档站使用稳定版静态文档工具，提供中英文首页、本地搜索、导航、移动端布局、品牌色和功能卡片。构建过程中发现仓库源码链接会被误判为站内死链，因此增加了经过测试的链接策略：`docs` 内链接保持站内导航，越过 `docs` 的源码、Skill 和示例链接自动跳转到 GitHub。

构建结果：成功渲染全部页面，没有忽略真实站内死链。

## 供应商矩阵

矩阵从构建后的运行时清单自动生成，而不是手工维护供应商数量。当前结果：

- 可发现：37
- 已认证：0
- 待真实验证：37

“可发现”只表示存在适配入口。“已认证”必须同时具有流式输出、工具调用、结构化结果、多轮会话和错误处理五项真实证据。认证台账为空是当前真实状态，不使用模拟测试制造认证结论。
