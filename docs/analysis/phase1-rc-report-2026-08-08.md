## 3. 当前仍需外部闭环

1. **TUI 人工验收**：Windows/Linux 自动化键盘、渲染和 CLI 测试已通过，但两个平台各一次真实终端人工操作仍需验收记录。
2. **PyPI 凭据**：当前环境未发现 PyPI 上传凭据。正式发布前需由维护者在本机安全设置，密钥不得写入仓库或对话。
3. **剩余公开渠道**：GitHub 源码与 8 个 npm 包已经发布；GitHub Release/Tag、PyPI 和文档站将在本报告同步后继续执行，其中 PyPI 受上一项阻断。

## 4. 安全处置说明

生产安装树的审计结果为 0。开发文档工具链存在 3 个已公开风险，影响本地开发服务器而非公开运行时包。仓库已移除文档开发与预览命令，只保留静态生产构建，并以精确包名、严重级别、缓解措施和到期日建立自动门禁。到期前必须升级到含修复的稳定工具版本或重新评估，不允许静默延长。

## 5. 一期完成判定

本地代码、发布物和自动化发布候选已就绪，但一期尚不能宣布正式完成。完成条件为：

- 候选提交进入公开仓库且 Windows/Linux CI 全绿；
- Windows/Linux TUI 人工交互清单通过；
- 同一版本完成 GitHub、npm、PyPI 和双语文档站发布；
- 发布后从公共 registry 再做一次全新安装冒烟。

在上述条件完成前，项目应继续标记为 **Beta Candidate**，不宣称生产就绪，也不作与成熟编程智能体产品等价的宣传。
