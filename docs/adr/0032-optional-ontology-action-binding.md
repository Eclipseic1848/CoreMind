# 可选本体绑定到现有工具运行时

## 背景

P3 交付《智能体构建能力图谱 V1.0.2》06.01–06.04 对应的可选能力。图谱原件 SHA-256 为 `71ac4675ea99413c383095b60b32f68c1e67c53603258deff9048007ade4fdac`。业务方维护术语、映射、约束与动作，沿用 CoreMind 的 TypeScript、Python、CLI 和工具权限。

## 决策

| 图谱项 | 使用的能力 | 框架提供的合同 |
| --- | --- | --- |
| 06.01 对象与关系建模 | RDFLib 读取 Turtle 并查询 RDF 图。Protégé 和 LinkML 可用于业务建模与编辑。 | 查询返回实例类型、属性值和有方向的关系，保留模型及资产摘要。两个示例只通过更换模型目录改变业务对象。 |
| 06.02 业务概念对齐 | 明确的源字段、身份和编码映射，借鉴 OpenRefine 的人工确认流程。 | 映射保留源记录、转换依据、映射版本和待确认候选。当前输入是结构化记录。关系库及跨源批量转换可按业务选择 Ontop 或 RMLMapper 接入。 |
| 06.03 规则约束与校验 | pySHACL 执行 SHACL Core 校验。 | 分别返回合规、违规、不可用。违规包含对象、路径、形状、规则类型和消息。加载指定版本可复验原规则。 |
| 06.04 业务动作语义 | 使用显式对象类、前置状态与期望状态，动作沿用已注册的 MCP 工具权限及效果回执。 | 动作在审批后重新校验条件与拟变更状态。业务回执决定完成、失败与未知。缺少确认时保留未知，重复请求不产生第二次业务调用。 |

首套引擎固定 RDFLib 7.6.0 和 pySHACL 0.40.2，以可选 Python 服务运行。仅加载宿主审阅的本地 Turtle 资产，禁用远程导入、动态 SHACL 规则及脚本。完整副作用流程仍由现有 CoreMind Harness 批准、记录并处理超时恢复。[RDFLib 发行包](https://pypi.org/project/rdflib/7.6.0/) · [pySHACL 发行包](https://pypi.org/project/pyshacl/0.40.2/) · [W3C SHACL](https://www.w3.org/TR/shacl/)

服务以只读配置接入 Agent。执行工具由写模式和独立令牌显式开放。宿主业务处理器使用自身的授权、持久事务和请求 ID。示例的附件、RDF 实例图与动作回执均为合成数据，动作回执只保存在演示进程内。生产恢复需要由业务系统查验原操作和当前状态。

## 验收

验证 CLI/YAML、TypeScript 和 Python 同步、异步四入口。启用后比较模型摘要与结构化结果。停用时继续普通任务。模型失败时从稳定工具目录返回不可用，远端服务断开按 Runtime 原有连接错误返回。再测试前置失败和审批拒绝均为零业务操作、回执核验、重复请求和未知后的禁止重发。[模块 SOP](../modules/manage-ontology/SOP.zh-CN.md)
