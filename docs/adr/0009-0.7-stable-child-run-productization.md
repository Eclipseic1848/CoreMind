# 0.7.0 作为 Child Run 产品化稳定版

CoreMind 的下一发布版本定为稳定版 `0.7.0`，因为本期将 Child Run 从内核合同提升为正式支持的产品能力，维护者明确选择稳定发布而不是 alpha 预发布；继续使用 `0.4.0-alpha.1` 会与既有 0.7.x Child Run 版本边界冲突，发布 `0.7.0-alpha.1` 又不能表达本期正式交付目标。

## Consequences

本期 P0 包含版本与发布事实重建、工程 CI 与发布资格拆分、`main` 保护、错误合同与运行配置安全、Child Run 产品化、最终候选的分层验收，以及通过全部门禁后的 Tag、GitHub Release、npm 与 PyPI 稳定发布。durable detach、Runs 运维 CLI、Supervisor、Web、Jobs、MCP、远程执行和无关依赖升级仍不在本期范围内；记录本决策不等于立即授权执行发布步骤，实际外部发布仍在发布门禁通过后由维护者确认。
