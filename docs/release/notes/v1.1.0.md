## 简体中文

### 功能与修复

- 支持标准技能文件与按需加载；保留原有技能配置，加载仍受权限、预算和持久化规则约束。
- 运行中追加指令和后续输入具有可查询的持久回执，区分接收、应用、消费、丢弃、重复、冲突与拒绝。
- 支持受控本地 MCP 服务及工具，沿用配置、工具授权、审批和子任务权限边界。
- 支持 HTTP MCP、资源读取与凭据引用，连接、调用、取消和关闭受原有网络与执行安全约束。
- 支持显式 MCP 交互认证、取消、刷新与退出；认证不会替代工具调用的授权和审批，凭据不进入模型上下文。
- 支持中英文工具按需发现与原 Schema 声明；目录、激活、撤回和暂停恢复按实际执行身份隔离，Child Run 不继承父任务的工具激活。
- 终端按 Run、Agent、步骤与 Call 身份展示工具时长、审批、结果及受控 Artifact 引用；修复合并输入、粘贴、中文编辑、退出收尾与可识别凭据的显示/错误净化问题。
- 文档站恢复导航与主题标题的正常渲染，同时保留配置与发布说明占位符的字面显示。
- FileRunStore 移除临时锁文件的冗余磁盘同步，保留完整 owner 原子发布、关键事实同步和原取消静止条件。
- Windows 本地 MCP 在服务启动前绑定专属 Job；关闭须确认全部后代退出，未确认时不报告静止。系统策略禁止辅助程序或 Job 时明确拒绝启动。

### 升级与兼容

- 原 Config v2 成功路径保留；延迟工具发现通过 Config v3 显式配置，不自动迁移旧项目。
- 保留 Protocol v1/v2 和统一 Node Runtime；Python SDK 仍依赖 Node.js 22.19 或以上，SDK 与随包 Worker 必须匹配。新增能力需按协商合同使用，不能把旧 Worker 忽略未知字段当作支持。
- 升级前备份持久状态；恢复、撤回与未知远端效果遵守原安全门，不能盲目重放。回滚使用匹配程序与状态备份。

### 验证范围与限制

- 功能证据包含本地受控 Provider、MCP 与认证服务夹具、真实文件/持久事实、SDK/Worker 调用及真实终端旅程；本地夹具通过不等于实际外部认证或 MCP 服务已互通认证。
- 实际外部 OAuth/MCP 互通与整体性能尚未认证；不作吞吐、时延或资源消耗保证。
- 本说明不预先宣称最终版本的 strict-provider、双平台候选与公开 Registry 回装已通过；最终资格与制品身份以对应发布运行、`release-manifest.json` 和 `SHA256SUMS.txt` 为准。
- 真实依赖与许可证义务继续保留，见 [第三方声明](https://github.com/Eclipseic1848/CoreMind/blob/v1.1.0/THIRD_PARTY_NOTICES.md) 和 [许可证](https://github.com/Eclipseic1848/CoreMind/blob/v1.1.0/LICENSE)。

## English

### Features and fixes

- Support standard skill files and on-demand loading while retaining existing skill configuration and permission, budget, and durability controls.
- Provide durable receipts for steering and queued follow-up input, distinguishing acceptance, application, consumption, discard, duplicate, conflict, and rejection.
- Support controlled local MCP servers and tools within the existing configuration, authorization, approval, and Child Run boundaries.
- Support HTTP MCP, resource reads, and credential references, with connection, invocation, cancellation, and shutdown governed by the existing network and execution controls.
- Support explicit interactive MCP authentication, cancellation, refresh, and logout. Authentication does not replace tool authorization or approval, and credentials stay outside model context.
- Support Chinese and English tool discovery with original Schema declarations. Catalogs, activations, withdrawals, and pause recovery are isolated by execution identity; Child Runs do not inherit parent activations.
- Correlate terminal tool duration, approvals, outcomes, and controlled Artifact references by Run, Agent, step, and Call. Fix coalesced input, paste handling, Chinese editing, exit settlement, and recognizable credential redaction in displays and errors.
- Restore documentation navigation and theme titles while preserving literal configuration and release-note placeholders.
- Remove redundant temporary-lock synchronization in FileRunStore while preserving complete atomic owners, critical Fact synchronization, and existing cancellation quiescence conditions.
- Bind local Windows MCP services to a dedicated Job before execution. Shutdown requires confirmation that all descendants exited; unconfirmed cleanup never reports quiescence. Policies blocking the helper or Job reject startup.

### Upgrade and compatibility

- Preserve existing Config v2 paths. Deferred discovery requires explicit Config v3 configuration; existing projects are not migrated automatically.
- Retain Protocol v1/v2 and the shared Node Runtime. Python still requires Node.js 22.19 or later and a matching bundled Worker. New capabilities require the negotiated contract; ignored unknown fields do not establish support in older Workers.
- Back up persisted state before upgrading. Recovery, withdrawal, and unknown remote effects retain the existing safety gates and do not permit blind replay. Rollback requires matching programs and state backups.

### Verification scope and limitations

- Feature evidence includes local controlled Provider, MCP, and authorization fixtures, real files and durable facts, SDK/Worker calls, and real terminal journeys. Local fixture success does not certify interoperability with external authorization or MCP services.
- External OAuth/MCP interoperability and overall performance are not certified. No throughput, latency, or resource consumption guarantee is made.
- These notes do not predeclare success of final-version strict-provider qualification, both-platform candidates, or public registry reinstall checks. Consult the corresponding release runs, `release-manifest.json`, and `SHA256SUMS.txt` for final evidence and artifact identity.
- Actual dependencies and license obligations remain intact; see [third-party notices](https://github.com/Eclipseic1848/CoreMind/blob/v1.1.0/THIRD_PARTY_NOTICES.md) and [license](https://github.com/Eclipseic1848/CoreMind/blob/v1.1.0/LICENSE).
