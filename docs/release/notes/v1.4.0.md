# v1.4.0 发布说明 / Release notes

状态：发布准备，尚未发布。此文件将随其余 v1.4.0 Issues 的验收补齐，不构成已发布声明。

Status: release preparation, not published. Remaining v1.4.0 changes will be added as their Issues pass acceptance.

## 缺陷修复 / Bug fixes

- **重试状态码边界：** 请求 ID 或长数字中的 `503`、`524` 等子串不再把未知 Provider 错误误分类为瞬态。Loop 保留原错误及脱敏审计，暂停等待人工处理；独立状态码、其他瞬态原因、配额排除和原重试预算保持不变。错误映射报告版本为 2。 ([#360](https://github.com/Eclipseic1848/CoreMind/issues/360))
- **Retry status-code boundaries:** digits such as `503` or `524` inside request IDs or longer numbers no longer misclassify unknown Provider errors as transient. Loop preserves the original error and redacted audit and pauses for human review. Standalone status codes, other transient reasons, quota exclusions, and existing retry budgets retain their behavior. The error mapping report version is 2. ([#360](https://github.com/Eclipseic1848/CoreMind/issues/360))

## 安全与依赖 / Security and dependencies

- **依赖修复：** fast-uri 更新至 3.1.9，CoreMind 网络工具使用 Undici 8.12.2；VitePress 的 Vite 更新至 6.4.5、API Extractor 的 minimatch 至 11.0.1，固定 Linux 后端开发源的 Zod 至 4.6.6、node-forge 至 1.4.2。定向覆盖不升级底层运行库，也不改变 Linux 后端来源版本。 ([#359](https://github.com/Eclipseic1848/CoreMind/issues/359))
- **获准接受的运行时依赖风险：** 按用户明确决定登记底层运行库 1.3.0 及其 minimatch 10.2.6 / Undici 8.10.2 已知风险；这不代表漏洞已修复。审计继续核对确切版本、安装位置、公告、等级上限及原到期日 2026-11-14，其他风险和报告失败仍阻断。公开 npm 消费者仍可能安装这条受影响链，不能依赖仓库 overrides。详见[安全说明](../../../SECURITY.md)。 ([#359](https://github.com/Eclipseic1848/CoreMind/issues/359))


- **Dependency fixes:** update fast-uri to 3.1.9 and CoreMind network tools to Undici 8.12.2; update VitePress's Vite to 6.4.5, API Extractor's minimatch to 11.0.1, and the fixed Linux backend build source's Zod to 4.6.6 and node-forge to 1.4.2. Scoped overrides do not upgrade underlying runtime or the Linux backend source version. ([#359](https://github.com/Eclipseic1848/CoreMind/issues/359))
- **Explicitly accepted underlying runtime risks:** record the user's decision to accept the known risks in underlying runtime 1.3.0 and its minimatch 10.2.6 / Undici 8.10.2 dependencies. Acceptance does not fix these vulnerabilities. Audits still enforce exact versions, installation locations, advisories, severity ceilings, and the original 2026-11-14 expiry; other risks and invalid reports remain blocking. Public npm consumers can still install the affected chain and cannot rely on repository overrides. See the [security policy](../../../SECURITY.en.md). ([#359](https://github.com/Eclipseic1848/CoreMind/issues/359))
