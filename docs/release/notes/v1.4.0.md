## 能力提升 / Improvements

- **跨语言任务与会话：** Protocol v2 增加独立能力和绑定身份的 DTO；TS、同步/异步 Python 通过同一 Node Worker 执行宿主注册的任务及分支/fork。任务工具权限与项目代码信任独立，原错误分类和超时保留；附真实进程崩溃后的结果复用与跨语言验收、安装入口和双语示例。 ([#367](https://github.com/Eclipseic1848/CoreMind/issues/367))
- **Cross-language tasks and sessions:** Protocol v2 adds negotiated capabilities and identity-bound DTOs. TS and sync/async Python use one Node Worker for trusted host tasks and branch/fork operations, preserving separate tool permissions and project-code trust, existing error classification and timeouts. Includes real-process result reuse, parity checks, package entry validation and bilingual examples. ([#367](https://github.com/Eclipseic1848/CoreMind/issues/367))

- **公共会话树与分支：** ChatSession 提供树查询、命名分支、持久选择与按消息节点 fork。下一轮读取所选分支，原会话写锁和活动 Run 限制继续生效。fork 生成新会话身份和来源关联，不复制执行身份或授权；附真实进程恢复、写故障测试及双语使用与回滚指南。 ([#366](https://github.com/Eclipseic1848/CoreMind/issues/366))
- **Public session trees and branches:** ChatSession exposes tree inspection, named branches, durable selection and message-node forks. The next turn reads the selected branch under existing writer ownership and active-Run constraints. Forks create new session identities and source links without copying execution identities or authorization, with real-process recovery, write-failure tests and bilingual usage and rollback guidance. ([#366](https://github.com/Eclipseic1848/CoreMind/issues/366))

- **稳定键调用与结果复用：** TaskPhaseContext.runCalls、executeTool 与 TaskSession.calls 将工具/子任务结果绑定父任务、阶段、版本和稳定键；重启后从原 Run/任务事实复用结果。参数、能力或调用顺序分歧会拒绝并留审计，未知外部效果仍受原恢复门约束。所有键共享原权限、预算、取消和 ChildRun 上限，附真实进程故障回归及离线示例。 ([#365](https://github.com/Eclipseic1848/CoreMind/issues/365))
- **Keyed calls and result reuse:** TaskPhaseContext.runCalls, executeTool and TaskSession.calls bind tool/child-task results to the parent task, phase, version and stable key. Reopening recovers results from the original Run and task records. Argument, capability or call-order divergence is rejected and audited; unknown external effects retain the original recovery controls. All keys share existing permissions, budgets, cancellation and ChildRun limits, with real-process failure regressions and an offline example. ([#365](https://github.com/Eclipseic1848/CoreMind/issues/365))

- **持久等待与唤醒：** TaskSession 将下一阶段、检查点和 sleepUntil 原子提交，重启后 nextWake 重算等待；wake 通过持久 sleepId/wakeId 防止重复或旧通知推进后续睡眠。宿主负责启动进程与 alarm，并显式恢复 ready 任务；原 Run、工具及测试超时保持。覆盖取消竞争、确认丢失及真实进程恢复，附离线宿主示例。 ([#364](https://github.com/Eclipseic1848/CoreMind/issues/364))
- **Durable waiting and wake:** TaskSession atomically commits the next phase, checkpoint and sleepUntil, then recomputes deadlines through nextWake after reopening. Persistent sleepId/wakeId bindings prevent duplicate or stale notifications from advancing later sleeps. The host owns process startup, alarms and ready-task resumption; existing Run, tool and test timeouts remain unchanged. Includes cancellation races, lost acknowledgements, real-process recovery and an offline host example. ([#364](https://github.com/Eclipseic1848/CoreMind/issues/364))

- **持久任务阶段与迁移：** 公共 TypeScript `TaskSession` 支持 start/query/resume/cancel，阶段检查点和版本迁移原子提交；模型与工具沿用既有 Runtime 权限、预算、取消及副作用事实。重启从已提交阶段继续，无法确认的 Run 保留等待人工核对，任务终态不重做。配套真实进程回归、离线示例和双语操作指南。 ([#363](https://github.com/Eclipseic1848/CoreMind/issues/363))
- **Durable phases and migration:** public TypeScript `TaskSession` supports start/query/resume/cancel with atomic phase checkpoints and explicit state migration. Models and tools retain existing Runtime permissions, budgets, cancellation and effect records. Reopening continues from the committed phase; unresolved Runs remain available for human reconciliation and terminal tasks do not run again. Includes real-process regressions, an offline example and bilingual operational guidance. ([#363](https://github.com/Eclipseic1848/CoreMind/issues/363))

- **任务原子提交：** 新增 internal `TaskCommitSession`，任务 checkpoint、typed document 与文本 entry 作为同一持久事实提交；revision、commitId、Schema 身份与单 writer 约束支持安全重开及崩溃恢复。旧 Session/Run/Workspace 数据不迁移，原子性不涵盖外部业务副作用。配套 ADR、双语指南、SOP/Skill、真实子进程回归和无模型示例。 ([#362](https://github.com/Eclipseic1848/CoreMind/issues/362))
- **Atomic task commits:** internal `TaskCommitSession` persists task checkpoints, typed documents and text entries as one authoritative record. Revisions, content-bound commit IDs, schema identity and a single writer support safe reopen and crash recovery. Legacy Session/Run/Workspace data stays unchanged; atomicity does not extend to external business effects. Includes an ADR, bilingual guidance, SOP/Skill, real child-process regressions and a model-free example. ([#362](https://github.com/Eclipseic1848/CoreMind/issues/362))

## 缺陷修复 / Bug fixes

- **CI 失败传播：** 拆分 Windows 工程门的多命令步骤，防止主 Python 测试等前序失败被后续成功覆盖；原命令、顺序、验收与超时保持，补充真实 PowerShell 反例回归（#376）。
- **CI failure propagation:** split multi-command Windows engineering steps so later success cannot mask earlier failures, including Python SDK tests. Preserve commands, ordering, acceptance and timeouts, with a real PowerShell regression (#376).

- **重试状态码边界：** 请求 ID 或长数字中的 `503`、`524` 等子串不再把未知 Provider 错误误分类为瞬态。Loop 保留原错误及脱敏审计，暂停等待人工处理；独立状态码、其他瞬态原因、配额排除和原重试预算保持不变。错误映射报告版本为 2。 ([#360](https://github.com/Eclipseic1848/CoreMind/issues/360))
- **Retry status-code boundaries:** digits such as `503` or `524` inside request IDs or longer numbers no longer misclassify unknown Provider errors as transient. Loop preserves the original error and redacted audit and pauses for human review. Standalone status codes, other transient reasons, quota exclusions, and existing retry budgets retain their behavior. The error mapping report version is 2. ([#360](https://github.com/Eclipseic1848/CoreMind/issues/360))

## 安全与依赖 / Security and dependencies

- **依赖修复：** fast-uri 更新至 3.1.9，CoreMind 网络工具使用 Undici 8.12.2；VitePress 的 Vite 更新至 6.4.5、API Extractor 的 minimatch 至 11.0.1，固定 Linux 后端开发源的 Zod 至 4.6.6、node-forge 至 1.4.2。定向覆盖不升级底层运行库，也不改变 Linux 后端来源版本。 ([#359](https://github.com/Eclipseic1848/CoreMind/issues/359))
- **获准接受的运行时依赖风险：** 按用户明确决定登记底层运行库 1.3.0 及其 minimatch 10.2.6 / Undici 8.10.2 已知风险；这不代表漏洞已修复。审计继续核对确切版本、安装位置、公告、等级上限及原到期日 2026-11-14，其他风险和报告失败仍阻断。公开 npm 消费者仍可能安装这条受影响链，不能依赖仓库 overrides。详见[安全说明](../../../SECURITY.md)。 ([#359](https://github.com/Eclipseic1848/CoreMind/issues/359))


- **Dependency fixes:** update fast-uri to 3.1.9 and CoreMind network tools to Undici 8.12.2; update VitePress's Vite to 6.4.5, API Extractor's minimatch to 11.0.1, and the fixed Linux backend build source's Zod to 4.6.6 and node-forge to 1.4.2. Scoped overrides do not upgrade underlying runtime or the Linux backend source version. ([#359](https://github.com/Eclipseic1848/CoreMind/issues/359))
- **Explicitly accepted underlying runtime risks:** record the user's decision to accept the known risks in underlying runtime 1.3.0 and its minimatch 10.2.6 / Undici 8.10.2 dependencies. Acceptance does not fix these vulnerabilities. Audits still enforce exact versions, installation locations, advisories, severity ceilings, and the original 2026-11-14 expiry; other risks and invalid reports remain blocking. Public npm consumers can still install the affected chain and cannot rely on repository overrides. See the [security policy](../../../SECURITY.en.md). ([#359](https://github.com/Eclipseic1848/CoreMind/issues/359))
