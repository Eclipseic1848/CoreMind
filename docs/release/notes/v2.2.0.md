## 简体中文

CoreMind 2.2.0 改进工作流、持久任务、Python SDK 与 CLI。CLI、TypeScript 和 Python 继续通过同一个 Runtime 执行。

- 工作流条件先解析配置再代入数据。多行内容按原值比较，`switch` 可命中多行和空字符串分支，持久任务错误会指出检查点失败的 Schema 规则。
- Python SDK 在关闭时报告 Worker 未退出和异常退出，审批回调异常会向 Worker 提交拒绝，明确拒绝的工具注册可重试。CLI 生成字符串项目名，`eval --json` 将互动审批与 JSON 输出写到不同的标准流。
- 知识服务在权限和版本过滤范围内优先返回明确编号的资料，支持回查已有目录中的旧 ID。
- 知识、记忆和本体的耗时工具不再阻塞服务的健康检查。整库遗忘先持久隐藏，再分批确认已完成的删除。本体动作在终态回执提交后发布图状态。
- 新增可复跑的工程、检索和公网评测入口。原验证使用合成资料，绑定 DeepSeek Flash 固定快照；固定任务集和真实业务任务请分别验收。

独立知识、Hindsight 记忆和本体更新至 0.1.1。升级与回退按各服务的备份和版本边界操作。外部业务动作以宿主保存的回执及对账结果为准。正式制品与资格以本次 GitHub Release 清单、严格候选工作流和公开安装记录为准。[2.1 到 2.2 迁移](https://github.com/Eclipseic1848/CoreMind/blob/main/docs/migrations/2.1-to-2.2.zh-CN.md) · [评测报告](https://github.com/Eclipseic1848/CoreMind/blob/main/examples/modules/evaluate-agents/GENERALIZATION.zh-CN.md)

## English

CoreMind 2.2.0 improves workflows, durable tasks, the Python SDK and the CLI. The CLI and both SDKs share the same Runtime.

- Workflow conditions parse configured operators before substituting data. Switch branches accept multiline and empty-string keys, and durable task validation reports the failed checkpoint schema rule.
- The Python SDK reports Worker shutdown failures, submits a denial after approval callback errors, and permits retry after a definitive registration rejection. CLI scaffolding preserves string project names. Interactive approval for `eval --json` goes to standard error.
- The knowledge service prioritizes explicit document identifiers within the authorized, effective candidate set and supports lookups for existing catalog identifiers.
- Long-running knowledge, memory and ontology tools leave service health checks responsive. Bank-wide forgetting hides records before committing confirmed deletions together. Ontology actions publish graph changes after the terminal receipt commits.
- Reproducible evaluation covers engineering fixtures, retrieval and a pinned public DeepSeek Flash snapshot. The reported datasets use synthetic material.

The independent knowledge, Hindsight memory and ontology packages move to 0.1.1. Follow each service's backup and rollback procedure. Production qualification requires your own data, permissions, model and reconciliation checks. Consult this release's artifact manifest, strict qualification run and public installation results for delivery evidence.
