## 简体中文

### 本版本完整变更日志

业务方现在可以从 `document-assistant` 模板创建资料整理项目，替换自己的资料、身份绑定、Skill 和本体模型。CLI/YAML、TypeScript、Python 同步和异步调用沿用同一个 Node Runtime。

- **知识。** Docling/RapidOCR 负责解析，BGE-M3 与 Qdrant 用于中文检索。结果给出文件、版本和位置。检索及解析 Markdown 表格引文时，数据行还带同一文件版本内的表头原文和行号，便于核对每个值对应的列。宿主可幂等导入、撤回版本、从原文重建索引。检索和旧引文解析均校验阅读范围。索引构建失败时保留上一份可用状态。[表格引文修复 #411](https://github.com/Eclipseic1848/CoreMind/issues/411)
- **长期记忆。** 宿主为 Hindsight 记忆库绑定读者和管理员。召回返回归属、版本和来源。写入、更正、遗忘及经验候选的确认由宿主管理，旧备份恢复后按遗忘回执清理。
- **Skill。** 根据业务任务说明生成可编辑草稿，使用标准 `SKILL.md`，按声明和权限读取资源。固定上游提交安装并以摘要冻结资源。旧 v1 快照沿用原恢复方式。脚本资源的读取与执行分别授权。资料助手按请求选择单份整理或两版比较，命中同一来源和位置后结束重复检索、说明范围并保存摘要。
- **工具。** 本地处理函数、stdio MCP 和 Streamable HTTP MCP 共用参数、取消和回执边界。可选 Playwright MCP 提供交互式浏览器。未知写入结果须凭原请求及回执核对。
- **可选本体。** 业务方提供 RDF 模型、映射、SHACL Core 约束与动作规则。RDFLib 和 pySHACL 返回约束位置、模型版本和动作前置条件。宿主另行授权执行并检查实际结果。
- **同轮多个工具。** 同一模型回合同时请求若干工具时，含独占或串行合同的批次按顺序执行；可并发的批次保留并发。审批、预算、持久化与工作区租约仍由 Runtime 执行。
- **Qwen 兼容端点。** 自定义 Provider 可显式使用 `qwen-chat-template` 将思考开关发送到 `chat_template_kwargs.enable_thinking`。旧 `qwen` 格式继续发送顶层开关。无效的显式格式会在配置阶段被拒绝，输出预算仍由 Agent 控制。
- **交付材料。** 五域建设指南给出能力图谱 04–08 的 20 项映射。资料助手模板提供双语说明、Skill 和四入口样例。P0 同步了依赖并清理已过期的审计例外。发布候选继续执行工程、稳定性、覆盖率、双平台真实 PTY、严格 Provider 及公开回装门禁。

2026-11-24，资料助手在 Windows 开发环境以两个项目的小型合成资料、独立读者和两个 Hindsight 个人记忆库完成七个逻辑案例。CLI 比较两版资料，TypeScript 整理草稿并检查发布条件，Python 同步入口验证另一项目的资料与偏好，异步入口验证更正和撤回。另有三个独立 ChatSession 分别验证未设置偏好、已确认表格偏好及更正为清单。真实 Qwen3.8-27B 调用知识、记忆与可选本体服务。原始记录保留失败尝试与复验，同一案例只计一次。[运行方法与边界](https://github.com/Eclipseic1848/CoreMind/blob/d87a160a1f437b656043f1b977248dba09482cbc/examples/modules/manage-ontology/LIVE-COMPOSITION.zh-CN.md) · [逐次运行及摘要](https://github.com/Eclipseic1848/CoreMind/blob/d87a160a1f437b656043f1b977248dba09482cbc/examples/modules/manage-ontology/live-composition-results.json)

## English

### Complete changelog for this version

Application teams can create a project from the `document-assistant` template and supply their own documents, identity bindings, Skills and optional ontology. YAML/CLI, TypeScript and both Python clients use one Node Runtime.

- **Knowledge.** Docling/RapidOCR parse sources and BGE-M3 with Qdrant retrieves Chinese text. Results identify the file, version and location. Retrieval and citation lookup return a Markdown table row with its header text and line number from the same file version so readers can verify which column each value belongs to. The host can import idempotently, withdraw a version and rebuild the index from source. Retrieval and citation lookup enforce reader scope. A failed index build preserves the previous usable state. [Table citation fix #411](https://github.com/Eclipseic1848/CoreMind/issues/411)
- **Long-term memory.** The host binds readers and administrators to Hindsight banks. Recall includes ownership, version and provenance. The host controls writes, corrections, forgetting and confirmation of experience candidates. Forgetting receipts govern cleanup after restoring an older backup.
- **Skills.** Generate editable drafts from a task description. Use standard `SKILL.md`, declare resources and authorize access. Install a pinned upstream commit and freeze resource digests. Existing v1 snapshots retain their original recovery behavior. Reading a script and executing it require separate authority. The document assistant follows the request to summarize one document or compare two versions. When searches return the same source and location, it stops repeating them, states the scope and saves the summary.
- **Tools.** Local handlers, stdio MCP and Streamable HTTP MCP share argument, cancellation and receipt semantics. Playwright MCP is an optional interactive browser. Reconcile an unknown write against its original request and receipt.
- **Optional ontology.** Applications supply RDF models, mappings, SHACL Core constraints and action rules. RDFLib and pySHACL report constraint locations, model identity and action preconditions. Execution requires separate host authorization and verification of the actual result.
- **Multiple tools in one turn.** A batch that includes an exclusive or serial tool executes in order. A parallel-eligible batch remains concurrent. The Runtime continues to enforce approval, budgets, persistence and workspace leases.
- **Qwen-compatible endpoints.** A custom Provider can select `qwen-chat-template` to send the thinking switch in `chat_template_kwargs.enable_thinking`. Existing `qwen` configurations keep the top-level switch. Invalid explicit formats fail configuration validation. The Agent's output budget still applies.
- **Delivery.** The construction guide maps the twenty items in capability domains 04–08. The document assistant includes a Skill, bilingual guidance and examples for all four entry points. P0 updated dependencies and removed expired audit exceptions. Candidate qualification retains engineering, stability, coverage, real PTYs on both platforms, strict Provider testing and public reinstall checks.

On 2026-11-24 the document assistant passed seven distinct cases in a Windows development workspace with two small synthetic corpora, separate project readers and two personal Hindsight banks. The CLI compared two versions. TypeScript summarized a draft and checked its publication preconditions. Synchronous Python checked the second project's documents and preference. Asynchronous Python checked a correction and withdrawal. Three independent ChatSessions checked an unset preference, a confirmed table preference and a correction to a list. Qwen3.8-27B used the knowledge, memory and optional ontology services. The record includes failed attempts and reruns. Each logical case counts once. ### Upgrade, limitations and artifacts

P3 used deterministic fixtures for its three-session check. P4-A used small synthetic documents in a Windows workspace with Qwen, BGE-M3, in-memory Qdrant, Hindsight/PostgreSQL and RDFLib/pySHACL across four entry points and three independent sessions. Python used a workspace-built Node Worker. The CLI preapproved writes in a temporary project. The SDK hosts limited writes to the project's summary.md. The knowledge service rebuilds its index from source and version state after restart. Hosts measure production capacity, latency and external action receipts. [P4-A runs and retests](https://github.com/Eclipseic1848/CoreMind/blob/d87a160a1f437b656043f1b977248dba09482cbc/examples/modules/manage-ontology/LIVE-COMPOSITION.en.md)
