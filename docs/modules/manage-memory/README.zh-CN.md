# 长期记忆与经验提炼

长期记忆让业务方在新的会话中复用已经确认的偏好、事实和经验。例如，用户允许资料整理助手在后续会话中优先输出表格，助手可在相同授权范围内检索这条偏好。更正为清单后，新会话只应召回当前版本。

P2-B 已接入 Hindsight OSS 1.2.3。宿主确定项目、主体、Agent 和会话分支，管理写入确认、更正、遗忘和经验是否生效。模型使用只读工具召回当前可见的记忆。会话历史、运行记录和知识资料仍按各自的数据合同管理。

[接入指南](GUIDE.zh-CN.md)和[可运行示例](../../../examples/modules/manage-memory/README.zh-CN.md)说明记忆的权限和使用过程。[开发 SOP](SOP.zh-CN.md)列出验收条件，实现和测试路径见[模块清单](module.yaml)。
