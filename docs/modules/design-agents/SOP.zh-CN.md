# Agent 构建开发 SOP

## 前置条件

先阅读 [模块说明](README.zh-CN.md)，确认业务负责人、输入输出、失败条件和权限边界。

## 执行步骤

1. 为 Agent 写单一职责和非目标。
2. 只挂载完成职责所需的工具。
3. 先用单 Agent 通过场景测试。
4. 只有职责确实分离时再增加 Agent。
5. 运行模块列出的测试，并执行 `npm run check:modules`。
6. 保存 Trace、评测和人工确认记录；未经明确授权不发布。

## 停止条件

遇到未确认业务规则、不可逆副作用、工作区外访问、真实密钥缺失或安全门禁失败时停止，向负责人请求决定。不要自行扩大业务范围。
