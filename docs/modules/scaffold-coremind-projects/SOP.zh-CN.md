# 模板与项目文档开发 SOP

## 前置条件

先阅读 [模块说明](README.zh-CN.md)，确认业务负责人、输入输出、失败条件和权限边界。

## 执行步骤

1. 检查已有工程语言证据。
2. 无法唯一判断时询问 TypeScript、JavaScript 或 Python。
3. 选择最接近的模板。
4. 生成后逐项确认业务 TODO。
5. 运行 check 和 eval。
6. 运行模块列出的测试，并执行 `npm run check:modules`。
7. 保存 Trace、评测和人工确认记录；未经明确授权不发布。

## 停止条件

遇到未确认业务规则、不可逆副作用、工作区外访问、真实密钥缺失或安全门禁失败时停止，向负责人请求决定。不要自行扩大业务范围。
