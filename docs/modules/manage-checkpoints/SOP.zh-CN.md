# Checkpoint、Diff 与恢复开发 SOP

## 前置条件

先阅读 [模块说明](README.zh-CN.md)，确认业务负责人、输入输出、失败条件和权限边界。

## 执行步骤

1. 执行写工具前确认 checkpoint_created。
2. 工具完成后确认 checkpoint 包含预期的执行后状态，再用 diff 检查实际变化。
3. 仅在用户明确要求时恢复；恢复前再次确认目标文件没有后续人工或并发修改。
4. 遇到 `checkpoint_conflict` 立即停止自动恢复，保留当前文件并转人工三方比较。
5. 对 bash 和未证明可恢复的自定义工具按不可逆副作用处理。
6. 运行模块列出的测试，并执行 `npm run check:modules`。
7. 保存 Trace、评测和人工确认记录；未经明确授权不发布。

## 停止条件

遇到未确认业务规则、不可逆副作用、工作区外访问、真实密钥缺失或安全门禁失败时停止，向负责人请求决定。不要自行扩大业务范围。
