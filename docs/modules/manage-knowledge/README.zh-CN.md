# 知识检索与引用

知识检索用于回答“哪一版资料的哪个位置支持这项结论”。业务项目提供原文、版本、有效期和阅读范围。接入检索后，应用可以展示命中的原文片段，并让读者打开对应版本核对。

业务项目可以从空目录只接入知识检索。业务方在自己的 Python 环境中安装 2.1.0 候选配套的 `coremind-knowledge-mcp` 0.1.0 本地 wheel，项目通过 MCP 连接本地服务。2.0.0 源码服务留下的目录和撤回记录可用于迁移。该组件尚未单独发布到 PyPI。[从空项目接入](GUIDE.zh-CN.md)

图谱 04.01 对应资料接入与解析，04.02 对应知识组织与索引，04.03 对应检索排序与取证，04.04 对应更新溯源与引用。[图谱与实现对照](../../guide/06-capability-construction.md)

例如，松屿资料室的两版索引把 `ST-17` 分别列在“榛果台”和“榆木台”。回答现行窗口时，需要引用二版的物件行。只有旧版记载的事项，不能据此作为现行规则作答。

P1 已验收。P2 增加增量导入、版本撤回和旧引文解析：同一文档 ID 与版本只接受一份内容，重复导入返回无变化；内容变化必须提升版本号；撤回后检索不再返回该版本，旧引文通过 `resolve_citation` 返回可用、已撤回或未知。接入见[使用指南](GUIDE.zh-CN.md)，效果验收见[开发 SOP](SOP.zh-CN.md)。[示例说明](../../../examples/modules/manage-knowledge/README.zh-CN.md)给出复核材料，[模块清单](module.yaml)登记实现和测试。
