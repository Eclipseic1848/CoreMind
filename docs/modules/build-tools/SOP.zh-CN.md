# 工具与业务能力开发 SOP

## 前置条件

先阅读 [模块说明](README.zh-CN.md)，确认业务负责人、输入输出、失败条件和权限边界。

## 执行步骤

1. 先定义输入 JSON Schema、副作用和幂等策略。
2. 用确定性代码实现，不把业务规则藏进提示词。
3. 覆盖成功、非法参数、依赖失败和重复调用。
4. 为写操作确认权限与恢复能力。
5. 在 Linux CI 中验证 bash 不能越界写入或联网。
6. 保持 Linux bash 串行执行，避免共享沙箱清理器并发互扰。
7. 运行模块列出的测试，并执行 `npm run check:modules`。
8. 保存 Trace、评测和人工确认记录；未经明确授权不发布。

## 停止条件

遇到未确认业务规则、不可逆副作用、工作区外访问、真实密钥缺失或安全门禁失败时停止，向负责人请求决定。不要自行扩大业务范围。
