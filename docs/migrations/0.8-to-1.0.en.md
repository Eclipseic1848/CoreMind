# Upgrade from 0.8 to 1.0

[简体中文](0.8-to-1.0.zh-CN.md)

1. Stop CLI, Worker, and SDK processes. Back up `.coremind/`, Sessions, Checkpoints, and external effect receipts.
2. Update every CoreMind npm package in use and the Python SDK to `1.0.1`. Requirements: Node.js >=22.19, Python >=3.10, and Git >=2.36 for Git tools. Releases and registries determine public availability.
3. Use the SDK's matching bundled Worker; do not mix strict Schema fingerprints. New programs read old journals; old programs cannot continue writing journals containing admission facts. Rollback requires pre-upgrade backups and matching old programs.
4. Config v2 and Protocol v1/v2 remain supported. v1 Python tools return `runId` only when the Worker advertises `scopedToolResults`; `callId` stays unchanged. Cancellation stops local waiting without claiming the external function stopped. Unconfirmed settlement means `quiescent: false`.
5. Recheck write approval, network policy, and the three Windows Shell conditions. Linux Web tools use a separate host network environment and cannot inherit Shell sandbox isolation claims.
6. Trace redacts recognizable credentials or fails closed. Credential-bearing step candidates fail with `redaction_failed`. Streaming fragments without whitespace may wait until the turn ends; an unclosed fragment exceeding 65,536 characters fails. Ordinary candidate text and hashes remain unchanged.
7. Recheck exhausted token/cost budgets, summary cancellation, pause-resume, late Python results, and `/abort`. `/exit` still waits for the current reply; `--print` stdout contains only the body.
8. When moving from `1.0.0` to `1.0.1`, Protocol v2 preserves every JSON Schema field in `tool_register.parameters`. Upgrade the SDK and bundled Worker together; do not mix old Schema fingerprints. To roll back, stop the processes, restore both SDK and Worker to `1.0.0`, and use the pre-upgrade backup for any persistent state that must be rolled back.

See the [changelog](../../CHANGELOG.en.md). Independently verify this version's live Provider, both-platform PTY, and public artifact evidence; previous release exceptions do not apply.
