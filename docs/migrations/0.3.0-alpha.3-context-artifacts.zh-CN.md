# 0.3.0-alpha.3 Context 与 Artifact 迁移

## 影响范围

Config v2 与 Protocol v1 请求无需修改。TypeScript 的 `RunMetrics.context`、`RunMetrics.artifacts` 与 `RunResult.artifacts` 都是新增可选字段，正常 Runtime 结果会填充它们。只读取既有字段或手工构造旧指标的调用方保持兼容。

## 行为变化

- 系统提示会按稳定前缀结构组装，语义仍来自原 Agent 指令、工具和 Skill。
- 超大工具输出不再把外部临时路径交给模型，而是导入 `.coremind/artifacts/` 并返回工作区相对引用。
- 检测到疑似凭据时不会保存 Artifact，也不会把命中内容交给模型。
- 不会自动创建项目 Memory。

## 回滚

1. 停止正在使用候选 Runtime 的进程。
2. 保留 `.coremind/artifacts/` 中仍需审计的文件及其 Trace 哈希。
3. 将完整版本族回退到 `0.3.0-alpha.2` 候选代码；不要只回退工具层。
4. 删除不再需要且未被审计记录引用的 Artifact。

回滚不会修改既有 Session、RunState 或 Checkpoint。若业务代码依赖新指标，先提供兼容读取再切换版本。
