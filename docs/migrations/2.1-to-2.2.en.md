# Upgrade from CoreMind 2.1 to 2.2

[简体中文](./2.1-to-2.2.zh-CN.md) · [Release notes](../release/notes/v2.2.0.md)

1. Stop affected CLI processes, SDK hosts and MCP services. Back up configuration, sessions, durable tasks, checkpoints and standalone service stores. Copy entire checkpoint directories, including the original `.json` files and any `.json.applied` files.
2. Pin the CLI and TypeScript SDK to `2.2.0`. Install the Python wheel with its Worker using `python -m pip install coremind-ai==2.2.0`. Upgrade the standalone knowledge, memory and ontology services you use to `0.1.1`.
3. Review custom workflow conditions. Operators come from the configuration template, and model or tool outputs supply operands. Read JSON from standard output and prompts from standard error for `coremind eval --json`.
4. Verify how hosts handle `WorkerShutdownError` and restart after uncertain tool registration results. Exercise your own flows for recovery, document lookup and permissions.

To roll back, stop writes, retain records from the upgrade, reinstall your pinned 2.1 packages and restore the pre-upgrade backup. Reconcile uncertain external operations against their original identity.
