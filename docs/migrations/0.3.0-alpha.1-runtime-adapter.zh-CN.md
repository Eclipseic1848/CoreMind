# 0.3.0-alpha.1 Runtime Adapter 迁移指南

## 受影响范围

- 核心运行依赖统一到同一精确版本族。
- Session 内部改由版本化仓库布局管理，同时继续提供稳定的 `session.dir/<id>.jsonl` 公共路径；CLI/SDK 返回路径不变。
- Provider 静态目录新增条目，但新增条目仍未认证。
- `coremind doctor` 新增 Runtime 兼容层检查。

## 普通用户

无需修改 `coremind.yaml`。升级后运行 `coremind doctor` 和 `coremind check --profile strict`。已有会话文件暂不自动删除；检测到只有旧布局文件时会明确停止，不会静默覆盖。备份与幂等迁移在 durable Session 批次交付。

## SDK 用户

业务代码应使用 `inspectRuntimeCompatibility()` 和 CoreMind 公共类型，不要直接依赖底层模型、消息或工具类型。现有配置、RunOutcome、权限和 Checkpoint 语义保持不变。

## 回滚

恢复升级前的源码和 Lockfile，重新安装依赖。核心依赖必须整体回滚，不能混用版本。会话迁移完成前保留旧文件原件。
