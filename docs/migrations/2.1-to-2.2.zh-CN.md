# 从 CoreMind 2.1 升级到 2.2

[English](./2.1-to-2.2.en.md) · [发布说明](../release/notes/v2.2.0.md)

1. 停止相关的 CLI、SDK 宿主与 MCP 服务。备份配置、会话、持久任务、检查点及独立服务的目录和账本。检查点按目录整体备份，包含原有 `.json` 与可能产生的 `.json.applied`。
2. 在独立环境将 CLI 和 TypeScript SDK 的包版本同步到 `2.2.0`。Python 使用 `python -m pip install coremind-ai==2.2.0` 安装含匹配 Worker 的 wheel。可分别将已使用的知识、记忆、本体安装件升级到 `0.1.1`。
3. 检查自定义工作流。条件运算符从配置模板读取。模型或工具返回的文本进入操作数，工作流判定应依据明确的比较。机器消费 `coremind eval --json` 时从标准输出读取 JSON，互动提示从标准错误读取。
4. 验证 Python 宿主处理 `WorkerShutdownError`，并核对遇到不确定工具登记回执时重启的操作。运行实际业务回归，包括重启恢复、资产回查以及工具权限。

回退时先停止写入，保留升级后的事实，再切回 2.1 固定安装件并恢复升级前备份。外部动作结果不确定时，先按原动作 ID 核对业务账本。
